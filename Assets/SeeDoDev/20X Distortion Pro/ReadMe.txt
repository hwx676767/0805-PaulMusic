[Intro]

20X Distortion Pro is a collection of 20 post-processing effects.
All effects are neat and have lots of customization options, also fully configurable through scripts.
This asset will add various video glitches,displacement and distortion visual effects in your project.

20X Distortion Pro includes 2 folders.				

1. HDRP - Effects for High Definition Render Pipeline post-processing system. 
2. URP - Effects for Universal Render pipeline.

///

[Setup]

Inside "Assets\SeeDoDev\20X Distortion Pro " folder you can find 2 folders.

1. “URP?for Universal Render.
2. “HDRP?for High Definition Render Pipeline.


Open needed folder and please follow the instructions in Documentation file.

URP: Native support via Render feature, so effects dont rely on any post processing system.
